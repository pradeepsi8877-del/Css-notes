css:- css stands for cascading style sheet which provide styling of our web pages .
there are three types of css 
1.inline css
2.internal css
3.external css

cascading :- when we overide the css properties of same selector this situation is knowen as cascading .


selector :-
1.id selector ->denoted by #
2.class selector ->denoted by .
3.tag selector ->h1 , p etc.
4.universal selector ->denoted by * which implies in complete body .


decendent selector :-
1.adjacent selector ->gap b/w two tags then is known as adjacent selector 
2.child selector ->denoted by >
3.sibling selector ->denoted by +
4.general selector:-denoted by ~(tilde sign)
