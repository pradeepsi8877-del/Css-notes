4. Reusable Button Components

5. CSS Design Tokens 

:root {

    /* Colors */
    --primary-color: #2563eb;
    --success-color: #16a34a;
    --danger-color: #dc2626;

    /* Typography */
    --font-body: Arial, Helvetica, sans-serif;
    --font-size-base: 16px;
    --font-weight-bold: 700;

    /* Spacing */
    --space-sm: 8px;
    --space-md: 16px;
    --space-lg: 24px;
}


/* Using the variables */

.button {

    background-color: var(--primary-color);

    padding: var(--space-md);

    font-family: var(--font-body);

    font-size: var(--font-size-base);

    font-weight: var(--font-weight-bold);
}

6. Accessibility Basics

  • Use readable font sizes.
  • Maintain proper line-height for paragraphs.
  • Use sufficient contrast between text and background.
  • Avoid extremely small text.
  • Do not communicate important information using color alone.
  • Keep typography and spacing consistent throughout the website.

7. Why Use CSS Variables?

Without Variables

The same color, font size and spacing values may have to be written repeatedly.


With Variables

We define common values once and reuse them throughout the entire website.


For example, changing --primary-color automatically changes every component that uses that variable.
